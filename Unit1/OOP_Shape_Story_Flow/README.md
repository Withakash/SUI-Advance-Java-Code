# OOP Story Flow
1. Step1_BasicClasses.java
- Problem: Duplicate code.

2. Step2_Inheritance.java
- Solution: Parent Shape class.
- Concept: Inheritance (IS-A).

3. Step3_Encapsulation_Polymorphism.java
- Make fields private.
- Add getters.
- Method Overloading.
- Method Overriding.
- Runtime Polymorphism using Shape reference.

4. Step4_AbstractClass.java
- Problem: Generic Shape should not be created.
- Make Shape abstract.
- Force child classes to implement draw() and area().

5. Step5_Interface.java
- New requirement: Some shapes can rotate.
- Use interface for optional capability (CAN-DO).
