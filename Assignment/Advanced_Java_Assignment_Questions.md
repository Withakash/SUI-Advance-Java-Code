## Assignment 1

### Part A --- Short-Answer Questions

**Attempt any 8 out of the following 10 questions.**\
**Marks: 8 × 5 = 40**

1.  Define Java Enterprise Edition (Java EE) and state its purpose in
    enterprise application development.
2.  Describe the major services that an application server offers to
    Java EE applications.
3.  Define a Servlet and explain its role in handling web requests.
4.  Compare the `doGet()` and `doPost()` methods, including their
    typical uses.
5.  Illustrate the JSP life cycle with a neat, labelled diagram and
    briefly describe its stages.
6.  What is the JSP Standard Tag Library (JSTL)? Explain why it is used
    in JSP pages.
7.  Explain the purpose of `EntityManager` in Java Persistence API
    (JPA).
8.  Describe Java Message Service (JMS) and its role in
    application-to-application communication.
9.  Explain the Model--View--Controller (MVC) pattern and the
    responsibility of each component.
10. Describe the Front Controller pattern and explain how it manages
    incoming requests.

### Part B --- Long-Answer Questions

**Attempt any 2 out of the following 4 questions.**\
**Marks: 2 × 10 = 20**

1.  Present the steps involved in packaging, deploying, and running a
    Java EE application on an application server.
2.  Discuss the different approaches used to maintain user state across
    multiple Servlet requests.
3.  Explain the architecture of JavaServer Faces (JSF), using a suitable
    diagram.
4.  Introduce the Spring Framework and discuss its key features and
    major components.
